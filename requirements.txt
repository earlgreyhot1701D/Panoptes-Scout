# ============================================================================
# DEPENDENCY LAYER EXPLANATION
# ============================================================================

# Layer 1: Scout Core (Deterministic)
#   Dependencies: pandas
#   Purpose: CSV profiling, statistics, data quality metrics
#   No external APIs, completely offline
#
# Layer 2: Gemini Analysis (LLM Interpretation)
#   Dependencies: google-generativeai
#   Purpose: Natural language explanation of data quality issues
#   Requires: GOOGLE_API_KEY environment variable
#   Requires: Internet connection
#
# Layer 3: Agent Orchestration (Conversational)
#   Dependencies: google-adk (when available)
#   Purpose: Agent interface, tool registration, context management
#   Used in: adk_agent.py (currently a placeholder)
#
# This layered approach means:
#   - You can use Layer 1 offline without any external dependencies
#   - Add Layer 2 (Gemini) for richer insights with an API key
#   - Add Layer 3 (ADK) for full agent workflow when available

# ============================================================================
# VERSION PINNING STRATEGY
# ============================================================================

# Major version: Locked (e.g., >=2.0.0,<3.0.0)
#   Reason: Major version changes indicate breaking changes
#   Benefit: Prevents incompatible upgrades while allowing bug fixes
#
# Minor version: Open (e.g., >=2.0.0)
#   Reason: Minor versions typically add features without breaking changes
#   Benefit: Allows security patches and performance improvements
#
# Patch version: Open
#   Reason: Patch versions are bug fixes and security updates
#   Benefit: Always get the latest stable fixes
